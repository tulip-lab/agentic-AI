## AI赋能教学与科研

本系列面向 BTBU 商科教师，围绕生成式人工智能与智能体技术，系统介绍从理解技术原理到组织教学科研工作流的方法，结合课程建设、资源开发、作业评价与科研协作，探讨如何提升 AI 应用的质量和可用性。

课程属于 **FLIP: Foundations and Engineering of Agentic AI**（**FLIP：智能体人工智能基础与工程实践**）课程体系，材料使用中文，无需 Python 编程基础。

| 项目 | 内容 |
| --- | --- |
| 适合对象 | 希望将 AI 应用于教学与科研的商科教师 |
| 课程形式 | 10 学时，五场专题，共 450 分钟 |
| 核心主题 | 智能体基础、AI Engineering、课程资源、作业评价与科研协作 |
| 学习方式 | 原理讲解、案例分析、应用演示与实践 |
| 案例情境 | Data Privacy：隐私泄露、数据泄密与差分隐私，并联系商科教学和研究任务 |

各场围绕独立主题展开，教师可根据教学与科研兴趣选择参加。
