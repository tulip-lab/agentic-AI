# 学习建议与实践成果

建议从自己熟悉的一门课程或一个研究问题出发，把专题学习转化为可核查、可修改、可复用的工作成果。

## 学习建议

1. **带着具体任务学习**。选择一个需要改进的环节，例如教学活动、作业说明或文献整理，明确受众、目标与限制。
2. **先理解，再迁移**。阅读案例或演示中的输入与结果，理解所用方法，再替换成适合自己学科的资料。
3. **比较并记录修改**。保留有意义的需求、资料与修改记录，比较调整前后的结果，判断改善来自哪里。
4. **核查后再采用**。检查事实、引文、教学适切性与隐私，将 AI 建议与自己的专业判断结合。

## 可形成的实践成果

| 专题 | 实践成果示例 |
| --- | --- |
| S01 技术基础 | 一项经提示词对照、审查和修订的课堂活动；说明教学背景带来的变化及教师核查理由 |
| S02 AI Engineering | 一份经工具与来源核对、智能体审核和限次修订的教学活动 Markdown 候选，附版本记录与教师决定 |
| S03 课程资源 | 一组相互对齐的教学目标、活动与资源示例 |
| S04 作业评价 | 一份作业与评价标准的改进方案，或预批改反馈审核记录 |
| S05 科研协作 | 一份文献证据表、研究计划或模拟评审修改记录 |

以上成果用于支持个人实践与反思，可根据所选专题和自身需要形成。关注任务是否更清楚、内容是否有依据、结果是否适合使用，以及哪些判断需要教师负责。

## 延伸与分享

将有效方法整理为可复用模板，在自己的课程或研究中持续检验和改进。分享时说明任务背景、使用方法与适用条件，避免展示学生、客户或保密研究信息。
