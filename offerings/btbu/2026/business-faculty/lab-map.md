# 实践与推荐工具

[项目首页](README.md) | [课程介绍](description.md) | [学习目标](learning-outcomes.md) | [专题大纲与安排](syllabus.md) | [实践与工具](lab-map.md) | [学习建议与成果](assessment-map.md)

实践围绕课程建设、作业评价与研究协作展开。教师可以先从任务表达、资料组织与结果审核入手，再根据兴趣探索可复用技能、可视化工作流和多智能体协作。

## 推荐工具

| 工具或平台 | 主要用途 | 适合的学习方式 | 相关专题 |
| --- | --- | --- | --- |
| [DeepSeek](https://chat.deepseek.com/) 等可访问的对话工具 | 比较基础提示词与教学背景、审查并修订课堂活动 | S01 使用对话界面；其他专题可按任务选择 | S01–S05 |
| [Flowise](https://docs.flowiseai.com/) | 在同一画布观察对话、计算、搜索、文档检索与多智能体审核 | S02 的可视化教学设计实践；可迁移到后续专题 | S02–S04 |
| [Hermes Agent](https://hermes-agent.nousresearch.com/docs/) | 探索可复用 Skills、工具使用与多智能体协作 | 后续专题的进阶参考 | S04、S05 |
| [OpenAlex](https://openalex.org/) 与本机绘图 MCP | 查询学术作品书目、生成可核查的教学活动流程图 | S02 区分 MCP 与一般网页搜索的功能 | S02 |
| [Slidev](https://sli.dev/) | 用 Markdown 组织与生成教学幻灯片 | 教学资源开发；可先审核生成内容，再深入编辑 | S03 |
| [Google Colab](https://colab.research.google.com/) / Jupyter | 阅读和运行共享 Lab notebook，分析代码与实验结果 | 可选编程进阶 | S01、S02、S05 |
| [OpenDP](https://docs.opendp.org/en/stable/) | 在合成数据上探索差分隐私统计发布与预算 | 可选编程进阶 | S01、S02、S05 |
| [Ollama](https://docs.ollama.com/) | 为 S02 文档检索提供本地嵌入模型；也可探索本地生成模型 | 主讲配置或技术进阶 | S02 |

这些工具服务于不同任务，参训教师无需全部安装。S01 可使用对话界面完成提示词对照；S02 可观察主讲配置好的统一 Flowise 画布和执行记录。编程与本地部署可按个人基础选择。模型、账号和数据的使用遵循本人所在机构的要求。

## 应用任务

| 方向 | 可探索的成果 |
| --- | --- |
| 任务与提示词 | 一项课堂活动的提示词对照、审查与修订 |
| 教学设计工作流 | 对话、工具、检索与多角色审核的执行轨迹；待教师核查的 Markdown 活动候选 |
| 课程资源 | 课程大纲、教学计划、讲义、课件与练习 |
| 课程知识助手 | 基于课程资料的问答与来源核查 |
| 作业与评价 | 作业说明、评价标准、反馈审核与预批改 |
| 科研协作 | 文献证据表、研究计划、写作修改与模拟评审 |

各专题对应的模块与 Lab 链接集中列在[专题大纲与安排](syllabus.md)。参考 Lab 包含不同技术深度，教师可根据兴趣阅读或选择进阶实践。S02 的公开课程资料检索与虚构课堂案例使用不同来源；使用公开、合成或获准发放的资料，关注来源、隐私与人工审核。

## 课程资源设计实践

[从课程资料到可审核教学资源](https://github.com/tulip-lab/agentic-AI-lab/tree/develop/M05-Knowledge-Agents/Applications/course-rag)串联学习目标、来源、活动、课件与质量检查。可选择阅读和审核的 L1 路线，或自定义与受控比较的 L2 路线。

## Data Privacy 贯通实践

[Data Privacy L1–L3 实验](https://github.com/tulip-lab/agentic-AI-lab/tree/develop/M06-Multi-Agent-Safety/Applications/data-privacy)使用合成数据：L1 区分统计推断与原始记录泄密，L2 比较隐私参数、误差和重复发布，L3 用 OpenDP 观察预算管理。教师可只选择阅读与判断活动；编程路线为自选进阶。差分隐私用于讨论统计发布，原始记录访问仍需单独管理。
