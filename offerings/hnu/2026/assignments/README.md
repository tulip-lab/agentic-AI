### Email subject and file naming

Replace `<StudentID>` and `<FullName>` with your student ID and full name.
Use Latin letters for the name and do not use spaces.

Your email subject must be exactly:

```text
[HNU2026] A1-<StudentID>-<FullName>
```

Name the attached archive exactly:

```text
HNU2026-A1-<StudentID>-<FullName>.zip
```

The archive must contain:

```text
HNU2026-A1-<StudentID>-<FullName>/
  HNU2026-A1-<StudentID>-<FullName>-Final.mp4
  HNU2026-A1-<StudentID>-<FullName>-Report.pdf
  HNU2026-A1-<StudentID>-<FullName>-PromptLog.pdf
  Iterations/
    HNU2026-A1-<StudentID>-<FullName>-V0.mp4
    HNU2026-A1-<StudentID>-<FullName>-V1.mp4
    HNU2026-A1-<StudentID>-<FullName>-V2.mp4
    HNU2026-A1-<StudentID>-<FullName>-V3.mp4
    HNU2026-A1-<StudentID>-<FullName>-V0-ContactSheet.png
    ...
```

If an accepted animation uses WebM or GIF, retain the required filename stem and change only the extension.
Additional iterations continue as `V4`, `V5`, and so on.
Open the ZIP archive before sending and confirm that every required file is readable.
