# FLIP: Agentic AI in Practice

FLIP stands for **Fundamentals of Learning and Intelligent Processing**. This open course from [TULIP Lab](https://www.tulip.academy) develops the conceptual judgment and practical skills needed to design, test, and govern useful agentic AI systems.

> The course is under active development. The `develop` branches contain the current learning sequence and practical materials; they are not a released offering.

## Start Here

- Read the [common-core outcomes and progression](COMMON-CORE.md).
- Review the [hub governance and contribution boundaries](HUB-GOVERNANCE.md).
- Check [licensing and third-party material boundaries](LICENSING.md).
- Select a module below, then complete its linked practicals in the [Lab repository](https://github.com/tulip-lab/agentic-AI-lab/tree/develop).
- Check the [offering index](offerings/README.md) for institution-specific delivery information.

## Prerequisites

You should be comfortable reading basic Python, working with files and web applications, and interpreting simple data or model outputs. Prior experience with large language models is useful but not required.

## Course Outcomes

After working through the common core, you should be able to:

1. **Explain** how models, prompts, tools, memory, retrieval, and orchestration contribute to an agentic system.
2. **Construct** visual and programmatic workflows that handle credentials and tool permissions safely.
3. **Evaluate** agent behaviour with normal, edge, failure, and adversarial cases.
4. **Design** knowledge-aware, stateful, and multi-agent solutions for bounded tasks.
5. **Compare** model adaptation, multimodal, local, and hosted deployment choices.
6. **Govern** an agent from prototype through evaluation, integration, and product readiness.

## Responsible Practice

Never commit credentials, personal data, private course material, or unreviewed model output. Treat tool calls as real capabilities: constrain permissions, validate inputs, test failure behaviour, and retain human review for consequential actions.
