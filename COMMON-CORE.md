# Agentic AI Common Core

[Home](README.md) | [Governance](HUB-GOVERNANCE.md) | [Offerings](offerings/README.md)

The common core is the institution-neutral learning sequence shared by public offerings. It defines what learners should be able to explain, build, test, and govern without imposing a university calendar, assessment weight, submission platform, or local policy.

## Learning Progression

1. **Foundations and representations:** M01-M02 establish safe API practice, model behaviour, learning fundamentals, and embeddings.
2. **Workflow construction:** M03-M04 move from visual composition to programmatic tools and actions.
3. **Knowledge, state, and collaboration:** M05-M06 add retrieval, persistent workflow state, multiple agents, and adversarial analysis.
4. **Adaptation and engineering:** M07-M08 compare model adaptation and multimodal techniques, then integrate evaluation, protocols, guards, and product decisions.

## Common-Core Outcomes

Learners should be able to:

- **Model** an agentic workflow as explicit components, state transitions, tools, and controls.
- **Implement** a bounded workflow using visual or programmatic orchestration.
- **Test** model and agent behaviour using reproducible evidence across expected and failure cases.
- **Analyse** trade-offs among retrieval, memory, fine-tuning, local inference, and hosted services.
- **Apply** privacy, security, provenance, accessibility, and human-oversight principles.
- **Communicate** system limits and evaluation results to technical and non-technical stakeholders.

## Concepts and Practicals

The conceptual module pages in this repository explain purpose, vocabulary, progression, and curated readings. Executable notebooks and tutorials are canonical in the [public Lab repository](https://github.com/tulip-lab/agentic-AI-lab/tree/develop). Stable module and session IDs connect the two without duplicating editable content.

## Offering Selection

An offering may select the whole sequence or a declared subset, add local scheduling and approved assignments, and link to institution policy. It must not silently change common-core identities or present development material as released.

## Development Status

The present common core is a structured foundation for further editorial work. Module boundaries and session identities are established; release-quality review, offering schedules, and adopted assignments remain separate approval decisions.
